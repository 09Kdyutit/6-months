# For Vanika

A cinematic, one-page romantic website built with React, Vite, TypeScript, Tailwind CSS, Framer Motion, and Three.js.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Personalize It

- Edit messages, cards, timeline entries, constellation reasons, and final reveal text in `src/data/content.ts`.
- Replace gallery images by updating the `gallery` array in `src/data/content.ts`.
- Existing photos are available in `public/photos`.
- Add background music at `public/music/song.mp3`, or update `music.src` in `src/data/content.ts`.

The music toggle never autoplays. Vanika can choose to start it.
